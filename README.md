# 🇿🇲 Zambia National Retail Intelligence Platform

A professional Streamlit app converted from the original Jupyter notebook.

## Features

| Page | What it shows |
|---|---|
| 📊 Executive Dashboard | KPI cards, revenue by city/category/store, YoY, monthly trend |
| 🔍 EDA & Trends | Seasonality, day-of-week, promotion impact, treemaps |
| 📈 Demand Forecasting | XGBoost & ARIMA models with metrics + feature importance |
| 🧠 Customer Segments | RFM analysis + K-Means (4 segments) + strategic recommendations |
| 🚨 Risk Detection | Stockout rates, demand anomalies (Z-score), overstock risk |
| 📋 Data Explorer | Interactive table, histograms, statistical summary |

## Run Locally

```bash
pip install -r requirements.txt
streamlit run app.py
```

## Deploy to Streamlit Community Cloud (Free)

1. Push this folder to a **public GitHub repository**
2. Go to [share.streamlit.io](https://share.streamlit.io)
3. Click **"New app"**
4. Select your repo, branch (`main`), and set **Main file path** → `app.py`
5. Click **Deploy** — live in ~2 minutes ✅
